# 8 周 Python 学习路径（面向 iOS / Web 开发者）

> 原则：每周都要有可运行产物，避免“只看不做”。

## 学习目标（8 周后）

- 独立搭建 Python 开发环境并管理依赖
- 能写出结构清晰、可测试的 Python 代码
- 能开发并部署一个基础 API 服务
- 能用 Python 处理真实数据并完成自动化任务

---

## 第 1 周：环境与语法基础

### 目标

- 完成 Python 开发环境初始化
- 熟悉核心语法、数据结构、函数定义

### 任务

1. 创建虚拟环境 `.venv`
2. 学习 `list/dict/set/tuple` 的常见操作
3. 写 20~30 个小练习（条件、循环、函数）

### 产出

- `exercises/week1/` 练习代码
- 一份 `README` 记录踩坑与对照（Swift/JS vs Python）

---

## 第 2 周：模块化、异常处理、文件读写

### 目标

- 从“脚本”走向“可维护代码”

### 任务

1. 拆分模块（`utils/`, `services/`）
2. 系统学习异常处理（`try/except/finally`）
3. 处理 JSON/CSV 文件读写

### 产出

- 一个小工具：读取本地 JSON 并生成统计报告

---

## 第 3 周：工程化基础（测试 + 规范）

### 目标

- 建立最低工程质量门槛

### 任务

1. 引入 `pytest` 并编写核心逻辑测试
2. 引入 `ruff` 检查代码风格
3. 学习 `requirements.txt` 管理依赖

### 产出

- `tests/` 目录（至少 10 个测试用例）
- `Makefile` 或脚本命令统一执行 `lint/test`

---

## 第 4 周：面向对象与常见设计方式

### 目标

- 在 Python 中正确使用类、抽象与组合

### 任务

1. 学习类、继承、`dataclass`
2. 用组合优先替代过度继承
3. 重构前 3 周代码，提升可读性

### 产出

- 一个可扩展的“任务处理器”示例（支持多策略）

---

## 第 5 周：Web 开发入门（FastAPI）

### 目标

- 快速搭建后端 API 能力

### 任务

1. 创建 FastAPI 项目
2. 实现路由、请求参数、响应模型
3. 使用 Pydantic 做输入校验

### 产出

- `GET/POST/PUT/DELETE` 基础接口各 1 个
- 自动生成接口文档（OpenAPI）

---

## 第 6 周：数据库与持久化

### 目标

- 掌握后端常见数据流

### 任务

1. 使用 SQLite + SQLAlchemy（或 SQLModel）
2. 建立基本数据模型与迁移思维
3. 完成 API 与数据库联动

### 产出

- 一个可本地运行的“待办事项 API”（含持久化）

---

## 第 7 周：异步、并发与性能基础

### 目标

- 理解 asyncio 的适用场景和限制

### 任务

1. 实作异步 HTTP 调用
2. 对比同步/异步在 I/O 场景的差异
3. 增加简单性能观测（耗时、日志）

### 产出

- 一个并发拉取外部接口并聚合结果的服务

---

## 第 8 周：整合项目与部署

### 目标

- 完成一个可展示、可复用的项目

### 任务

1. 整理目录结构、配置、日志与错误处理
2. 补齐测试与 README
3. 用 Docker 打包并本地运行

### 产出

- 一个完整项目仓库（建议：内容管理 API / 任务管理 API）
- 项目文档包含：启动方式、接口示例、测试方式、架构说明

---

## 每周固定节奏（建议）

- 周一：学习新概念 + 写最小示例
- 周三：实现主任务
- 周五：补测试 + 重构 + 写周总结
- 周末：做一个小扩展功能

---

## 你可以优先使用的技术栈（务实组合）

- Web 框架：FastAPI
- 测试：pytest
- 规范：ruff
- 数据库：SQLite（本地）→ PostgreSQL（进阶）
- 部署：Docker + 任意云主机

---

## 完成标准（自检清单）

- [ ] 我能在 10 分钟内从零初始化一个 Python 项目
- [ ] 我写的接口有类型标注、参数校验、测试
- [ ] 我能排查常见异常并定位日志
- [ ] 我有一个可运行、可演示、可复用的小项目
