# 第 1 周训练包（可直接开练）

> 适用人群：有 iOS / Web 开发经验，第一次系统学习 Python。  
> 训练目标：7 天内完成语法 + 数据结构 + 函数 + 文件处理 + 小型 CLI。

## 使用方式（建议）

1. 每天 60~90 分钟
2. 先做 `exercises/week1/questions.md` 对应题目
3. 完成后再对照 `exercises/week1/answers/` 参考答案
4. 每天写 5 分钟复盘：今天卡点、明天优化点

---

## Day 1：语法与流程控制

**目标**：熟悉变量、输入输出、条件、循环、字符串格式化。

题目：

- E01 Hello Python（输出欢迎语）
- E02 BMI 计算器（输入身高体重输出 BMI）
- E03 成绩评级（if/elif）
- E04 九九乘法表（循环 + 格式化）

验收标准：

- 能独立写出 `if/elif/else`
- 能用 `for` 循环生成结构化输出

---

## Day 2：核心数据结构

**目标**：掌握 list/dict/set/tuple 的高频用法。

题目：

- E05 词频统计（list + dict）
- E06 去重与排序（set + sorted）
- E07 用户索引构建（list[dict] -> dict）
- E08 统计标签 TopN

验收标准：

- 能把“数组对象”转换为“按 id 的索引映射”
- 能独立处理去重、计数、排序三件套

---

## Day 3：函数与模块化

**目标**：学会拆函数、参数设计、返回值结构化。

题目：

- E09 价格结算函数（折扣、满减）
- E10 密码强度校验器（规则组合）
- E11 统计函数库（max/min/avg）
- E12 错误处理与输入校验

验收标准：

- 代码不再是一个大脚本，而是拆成多个函数
- 出错时能给出可读报错信息

---

## Day 4：文件与 JSON

**目标**：完成本地数据读取、处理、写回。

题目：

- E13 读取 JSON 用户数据
- E14 生成部门统计报表
- E15 导出处理结果到 JSON

验收标准：

- 会使用 `json.load/json.dump`
- 能把“原始数据 -> 新结构数据”完整跑通

---

## Day 5：小型 CLI 项目

**目标**：把前 4 天能力整合成可运行工具。

题目：

- E16 Todo CLI（新增、列表、完成、删除）
- E17 参数解析（可选，`argparse`）

验收标准：

- 可以通过命令行执行核心功能
- 数据能持久化到本地 JSON 文件

---

## Day 6：质量提升

**目标**：加入基础测试与代码规范。

任务：

- 给 E09/E10/E11 写至少 8 个测试
- 引入 `ruff` 并修复基础告警

---

## Day 7：复盘与重构

**目标**：形成可展示的学习成果。

任务：

- 整理 `README`：项目介绍、运行方式、示例输入输出
- 重构 1~2 个你最不满意的题目解法
- 写一份“Swift/TS 到 Python 的迁移总结”

---
