# 第 2 周训练包（模块化 + 异常处理 + 文件读写）

> 适用人群：完成第 1 周基础语法，准备进入“可维护代码”阶段。  
> 本周目标：从“单文件脚本”升级为“有结构、有错误处理、可复用”的小项目。

## 本周核心能力

- 会拆模块：把业务逻辑从入口脚本中分离出来
- 会处理异常：输入异常、文件异常、业务异常
- 会读写数据：JSON/CSV 的加载、转换、导出
- 会做基础工程组织：`src/`、`tests/`、`data/` 的最小结构

---

## Day 1：模块拆分与项目结构

**目标**：把一个脚本拆成多个模块，入口清晰。

题目：

- W2-E01 从“单文件”重构为 `main.py + services.py + utils.py`
- W2-E02 设计 `parse_users`、`build_index`、`print_summary` 三个函数
- W2-E03 使用 `if __name__ == "__main__":` 组织入口

验收标准：

- `main.py` 仅做流程编排，不写核心业务细节
- 业务函数可单独调用（可测试）

---

## Day 2：异常处理与输入校验

**目标**：避免程序“一错就崩”，做到可预期失败。

题目：

- W2-E04 安全解析整数/浮点数（非法输入给默认值）
- W2-E05 读取不存在文件时，输出可理解错误提示
- W2-E06 业务规则异常（例如：年龄不能为负）

验收标准：

- 使用 `try/except/else/finally`
- 错误信息可读，且不暴露无意义堆栈给普通用户

---

## Day 3：JSON 数据处理

**目标**：能完成“读取 -> 清洗 -> 统计 -> 导出”。

题目：

- W2-E07 读取用户 JSON（含脏数据）
- W2-E08 清洗字段（缺失值、类型不一致）
- W2-E09 按部门和角色做双维度统计
- W2-E10 导出统计结果 JSON

验收标准：

- 数据清洗函数和统计函数独立
- 导出结果结构稳定，便于后续 API 消费

---

## Day 4：CSV 读写与报表

**目标**：掌握 CSV 常见处理流程。

题目：

- W2-E11 读取 `orders.csv`
- W2-E12 计算每个用户总消费、订单数、客单价
- W2-E13 导出 `order_report.csv`

验收标准：

- 使用 `csv.DictReader/DictWriter`
- 对缺失字段或异常金额有兜底策略

---

## Day 5：整合 mini project（数据报表 CLI）

**目标**：做一个真正可跑的小工具。

题目：

- W2-E14 命令行参数：输入文件路径、输出目录
- W2-E15 支持 JSON/CSV 两种输入格式
- W2-E16 输出 summary + 导出报表

验收标准：

- 命令可运行：`python main.py --input ... --output ...`
- 目录下可生成结果文件并可复现
