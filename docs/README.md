# Python 学习文档（iOS / Web 开发者版本）

这份文档集合是给**已经有 iOS 与 Web 开发经验**、想快速把 Python 用起来的你。

## 建议阅读顺序

1. [Python for iOS / Web 开发者快速对照](./python-for-ios-web-dev.md)
2. [8 周 Python 学习路径（以实作为主）](./python-learning-path-8-weeks.md)

## 你可以先达成的三个目标

- 在 30 分钟内完成开发环境与第一个 CLI 工具
- 在 1 周内用 Python 读写 API、处理 JSON、完成单元测试
- 在 8 周内做出可部署的小型后端服务（FastAPI）与数据处理脚本

## 建议工作流（沿用你熟悉的开发习惯）

- 用 `venv` 管理 Python 环境（类似 iOS 的 scheme / Web 的 node_modules 隔离）
- 用 `ruff + pytest` 作为基本质量门槛（类似 ESLint + Jest）
- 以小步提交（small commits）积累练习成果
