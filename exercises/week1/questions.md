# Week 1 题目清单（按天）

> 完成建议：每天 4 题左右，总计 17 题。  
> 命名建议：`eXX_题目名.py`，例如 `e01_hello_python.py`。

---

## Day 1：语法与流程控制

### E01 Hello Python

- 要求：输出 `Hello, Python Learner!`
- 进阶：把你的名字拼进输出字符串

### E02 BMI 计算器

- 要求：输入身高（米）和体重（kg），输出 BMI（保留 2 位小数）
- 公式：`BMI = 体重 / (身高 ** 2)`

### E03 成绩评级

- 要求：输入分数，按区间输出 `A/B/C/D/F`
- 区间：90+ A，80~89 B，70~79 C，60~69 D，<60 F

### E04 九九乘法表

- 要求：打印 1~9 的乘法表，格式整齐

---

## Day 2：数据结构

### E05 词频统计

- 输入：`["python", "swift", "python", "js", "python", "js"]`
- 输出：每个词出现次数（dict）

### E06 去重排序

- 输入：`[5, 2, 2, 9, 1, 5, 3]`
- 输出：去重后升序列表

### E07 用户索引构建

- 输入：`[{"id": 1, "name": "A"}, {"id": 2, "name": "B"}]`
- 输出：`{1: {...}, 2: {...}}`

### E08 标签 TopN

- 输入：一组标签列表
- 输出：出现次数前 3 的标签（按次数降序）

---

## Day 3：函数与模块化

### E09 价格结算函数

- 实现 `calc_price(price, discount=1.0, coupon=0)`  
- 返回：最终金额，最低不低于 0

### E10 密码强度校验

- 规则：长度 >= 8，且包含大小写字母、数字、特殊字符
- 输出：`"weak"` / `"strong"`

### E11 统计函数库

- 输入：数字列表
- 输出：最大值、最小值、平均值（dict）

### E12 输入校验与异常处理

- 要求：把字符串安全转换为整数
- 非法输入时返回默认值并提示错误

---

## Day 4：文件与 JSON

### E13 读取 JSON

- 从本地 `sample_users.json` 读取用户数据
- 输出：用户总数

### E14 部门统计报表

- 基于用户数据按 `department` 分组计数
- 输出：`{"iOS": 2, "Web": 3, "Backend": 1}` 这类结构

### E15 写入处理结果

- 把 E14 结果写入新文件 `department_report.json`

- 数据：保存到本地 `todo.json`

### E17 Todo CLI（进阶）
