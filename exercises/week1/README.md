# Week 1 练习说明

本目录是第 1 周可直接开练内容，建议按题号顺序完成。

## 目录结构

```text
exercises/week1
├── README.md
├── questions.md
├── starter
│   ├── README.md
│   ├── day1_template.py
│   ├── day2_template.py
│   ├── day3_template.py
│   ├── day4_template.py
│   └── day5_template.py
└── answers
    ├── README.md
    ├── day1
    ├── day2
    ├── day3
    ├── day4
    └── day5
```

## 建议执行节奏

1. 先做 `questions.md`，不要先看答案
2. 每完成 2~3 题，提交一次 git commit
3. 每天最后做一次重构：命名、函数拆分、异常处理

## 运行方式

```bash
python3 exercises/week1/starter/day1_template.py
```

如果你已经完成对应题目，也可以直接运行答案文件，例如：

```bash
python3 exercises/week1/answers/day1/e01_hello_python.py
```
